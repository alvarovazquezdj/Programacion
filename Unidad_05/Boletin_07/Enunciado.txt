Ejercicio 10. Sistema de gestión de entradas de un concierto
Una empresa organiza un concierto y dispone de los siguientes números de entrada vendidos:
int[] entradas = {1001, 1003, 1005, 1008, 1012, 1015, 1020};


Las entradas están ordenadas de menor a mayor.

Desarrolla una aplicación que permita gestionar las ventas y cancelaciones mediante el siguiente menú:
===== GESTIÓN DE ENTRADAS =====

1. Mostrar entradas vendidas
2. Comprobar una entrada
3. Vender una nueva entrada
4. Cancelar una entrada
5. Consultar entradas de un intervalo
6. Mostrar las últimas cinco entradas numeradas
7. Crear una copia de seguridad
8. Restaurar la copia de seguridad
9. Mostrar estadísticas
10. Salir


El programa deberá cumplir los siguientes requisitos:
	Venta de entradas: solicitar un número de entrada y comprobar si ya existe. Si no existe, insertarlo en su posición correspondiente, manteniendo el array ordenado.
	Cancelación: solicitar un número de entrada y eliminarlo del array. Si no existe, mostrar un mensaje de error.
	Consulta de intervalo: solicitar dos números y crear un nuevo array con todas las entradas vendidas comprendidas entre ambos límites.
	Últimas cinco entradas numeradas: crear un nuevo array con los cinco números de entrada más altos. Si hay menos de cinco, mostrar únicamente los disponibles.
	Copia de seguridad: guardar una copia independiente del array de entradas actual.
	Restauración: recuperar el contenido de la última copia de seguridad realizada. Si no existe ninguna copia, mostrar un mensaje de error.
	Estadísticas: mostrar el número total de entradas vendidas y los números de entrada menor y mayor. Si no existen entradas, mostrar un mensaje adecuado.
