Ejercicio 1. Mi primer array
Crea un programa que declare un array de 8 números enteros con los siguientes valores:

{12, 5, 8, 21, 3, 17, 9, 14}

El programa debe:
1. Mostrar el número total de elementos utilizando length.
2. Mostrar el primer y el último elemento.
3. Mostrar todos los elementos utilizando Arrays.toString().
4. Recorrer el array mediante un bucle for, mostrando el índice y el valor de cada elemento.
Ejemplo de salida:
Número de elementos: 8
Primer elemento: 12
Último elemento: 14

Array: [12, 5, 8, 21, 3, 17, 9, 14]

Posición 0: 12
Posición 1: 5
...
Posición 7: 14

1. Rellénalo con los números del 1 al 20 utilizando un bucle for.
2. Muéstralo con Arrays.toString().

Ejercicio 4. Tabla de multiplicar
Solicita al usuario un número entero y crea un array de 10 posiciones.
1. Almacena en el array los diez primeros múltiplos del número introducido.
2. Muestra el array utilizando Arrays.toString().
3. Recorre el array con un for para mostrar la tabla de multiplicar, del 1 al 10.
Ejemplo para el número 5:
Array: [5, 10, 15, 20, 25, 30, 35, 40, 45, 50]

5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50

Ejercicio 5. Recorridos con for y for-each
Declara el siguiente array:
int[] numeros = {4, 7, 2, 9, 5, 1, 8};


Realiza las siguientes operaciones:
1. Muestra todos los elementos mediante un for tradicional.
2. Muestra todos los elementos mediante un for-each.
3. Muestra los elementos en orden inverso.
4. Calcula la suma de todos los elementos utilizando for-each.
5. Calcula la media aritmética.
Pregunta: ¿Por qué es más sencillo recorrer un array en orden inverso utilizando for que utilizando for-each?

Ejercicio 12. Control de temperaturas
Disponemos de las temperaturas máximas de una semana:

El programa debe:
1. Mostrar todas las temperaturas con Arrays.toString().
2. Calcular la temperatura media.
3. Indicar qué días han superado la media.
4. Encontrar el día con la temperatura máxima.
5. Ordenar las temperaturas de menor a mayor.

Ejercicio 13. Estadísticas de una encuesta

1. Muestre todas las respuestas.
2. Calcule la valoración media.
3. Cuente cuántas personas han dado cada puntuación (1, 2, 3, 4 y 5).

Ejercicio 14. Inventario de productos
Una tienda almacena las existencias de 8 productos en un array.

Inicialmente, todos los productos tienen 10 unidades. Utiliza Arrays.fill() para establecer ese valor.

Implementa un menú que permita:
1. Consultar todas las existencias.
2. Añadir unidades a un producto, indicando su posición.
3. Vender unidades de un producto, comprobando que haya suficientes.
4. Mostrar el producto con mayor y menor stock.
5. Ordenar y mostrar las cantidades disponibles.
6. Salir.
Restricción: el programa debe mantener el menú activo hasta que el usuario seleccione salir.

Ejercicio 15. Análisis de números
Desarrolla un programa que permita introducir 15 números enteros y almacenarlos en un array.

Una vez introducidos, debe mostrar un menú con las siguientes opciones:
--- ANÁLISIS DE NÚMEROS ---

1. Mostrar array original
2. Mostrar números pares
3. Mostrar números impares
4. Calcular suma y media
5. Mostrar mayor y menor
6. Buscar un número
7. Ordenar de menor a mayor
8. Mostrar en orden inverso
9. Reiniciar todos los valores a cero
10. Salir


Requisitos:
- Utiliza Arrays.toString() para mostrar el array completo.
- Utiliza Arrays.sort() para ordenar.
- Utiliza Arrays.fill() para reiniciar.
- Utiliza length en los recorridos.
- Emplea tanto for como for-each en diferentes operaciones.
- El menú debe repetirse hasta seleccionar la opción 10.
- Al ordenar, el array debe quedar modificado para las siguientes operaciones.
