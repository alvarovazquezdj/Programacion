### Ejercicio 1. Análisis de ventas de una tienda

Una tienda registra el importe total de sus ventas diarias durante un mes de 30 días. Los importes se almacenan en un array de números reales.

Desarrolla un programa que:

1. Solicite los importes de los 30 días, validando que ninguno sea negativo.
2. Calcule la recaudación total, la media diaria y el día con mayor y menor recaudación.
3. Determine cuántos días se ha superado la media mensual.
4. Solicite al usuario dos números de día y cree un nuevo array con las ventas correspondientes a ese intervalo, incluidos ambos extremos.
5. Calcule la recaudación y la media del intervalo seleccionado.
6. Cree una copia de las ventas del mes, la ordene de menor a mayor y muestre los cinco importes más altos.
7. Indique cuántos días no se ha realizado ninguna venta.

Implementa, al menos, las siguientes funciones:

```
static double calcularMedia(double[] ventas)
static int buscarDiaMayorVenta(double[] ventas)
static double[] obtenerVentasPeriodo(double[] ventas, int inicio, int fin)
```

Los días se numerarán del 1 al 30. El array original no deberá modificarse al ordenar los importes.

### Ejercicio 2. Control de calidad de una fábrica

Una fábrica produce piezas metálicas cuyo peso ideal es de 250 gramos. Se han medido 20 piezas y sus pesos se encuentran almacenados en un array.

Una pieza se considera válida si su peso está comprendido entre 245 y 255 gramos, ambos incluidos.

Desarrolla un programa que:

1. Solicite los pesos de las 20 piezas, comprobando que sean positivos.
2. Muestre cuántas piezas cumplen las especificaciones y cuántas son defectuosas.
3. Cree un array que contenga únicamente los pesos de las piezas defectuosas, con el tamaño exacto necesario.
4. Calcule el peso medio de las piezas válidas.
5. Busque la pieza cuyo peso esté más alejado del peso ideal e indique su posición y la desviación.
6. Solicite el número de una pieza y permita repetir su medición, sustituyendo el valor anterior.
7. Vuelva a calcular las estadísticas después de modificar la medición.

Implementa funciones para determinar si una pieza es válida, obtener las piezas defectuosas y calcular la desviación de un peso.

El programa deberá funcionar correctamente aunque todas las piezas sean válidas o todas sean defectuosas.

6. Solicite una cantidad mínima de existencias y genere un array con los índices de los productos cuyo stock del viernes sea inferior a ese límite.
7. Permita actualizar el stock de un producto del viernes y vuelva a mostrar las diferencias.

Utiliza `Arrays.equals()` para comparar los inventarios e implementa una función que reciba ambos arrays y devuelva el array de diferencias.

### Ejercicio 15. Sistema de gestión de una biblioteca

Una biblioteca desea desarrollar una aplicación para gestionar su catálogo y los préstamos de libros.

Los libros se identifican mediante códigos numéricos positivos. Se utilizarán dos arrays:

- `catalogo`: almacena los códigos de todos los libros de la biblioteca, ordenados de menor a mayor.
- `prestados`: almacena los códigos de los libros que actualmente están prestados, también ordenados.

Inicialmente, el catálogo contendrá:

```
int[] catalogo = {101, 105, 110, 115, 120, 125, 130, 135, 140, 145};
int[] prestados = {105, 120, 135};
```

Desarrolla una aplicación con el siguiente menú:

```
========== GESTIÓN DE BIBLIOTECA ==========

1. Mostrar catálogo completo
2. Buscar un libro
3. Añadir un libro al catálogo
4. Eliminar un libro del catálogo
5. Registrar un préstamo
6. Registrar una devolución
7. Mostrar libros disponibles
8. Mostrar libros prestados
9. Consultar libros por intervalo de códigos
10. Crear copia de seguridad
11. Restaurar copia de seguridad
12. Mostrar estadísticas
13. Salir
```

El programa deberá cumplir los siguientes requisitos:

1. Buscar libro: comprobar si existe en el catálogo e indicar si está disponible o prestado.
2. Añadir libro: insertar su código en el catálogo, manteniendo el orden y evitando duplicados.
3. Eliminar libro: eliminar un libro del catálogo, siempre que exista y no esté prestado.
4. Registrar préstamo: comprobar que el libro existe y está disponible. Si se cumplen ambas condiciones, insertar su código en el array de prestados.
5. Registrar devolución: buscar el código en el array de prestados y eliminarlo.
6. Mostrar disponibles: crear un nuevo array con los códigos de los libros del catálogo que no estén prestados.
7. Consultar intervalo: solicitar dos códigos y crear un array con todos los libros del catálogo comprendidos entre ambos límites.
8. Copia de seguridad: guardar copias independientes de los dos arrays.
9. Restauración: recuperar ambos arrays a partir de la última copia de seguridad.
10. Estadísticas: mostrar el número total de libros, los disponibles, los prestados y el porcentaje de libros prestados.

Implementa, como mínimo, las siguientes funciones:

```
static int buscarLibro(int[] libros, int codigo)

static int[] insertarOrdenado(int[] libros, int codigo)

static int[] eliminarLibro(int[] libros, int codigo)

static boolean estaPrestado(int[] prestados, int codigo)

static int[] obtenerDisponibles(int[] catalogo, int[] prestados)

static int[] obtenerLibrosIntervalo(int[] libros, int minimo, int maximo)
```

Restricciones adicionales:

- Ambos arrays deben mantenerse ordenados sin utilizar `Arrays.sort()` después de insertar o eliminar elementos.
- No se permiten códigos duplicados.
- No se puede prestar un libro inexistente ni registrar dos préstamos del mismo ejemplar.
- No se puede eliminar del catálogo un libro prestado.
- Las copias de seguridad deben ser independientes de los arrays originales.
- El programa debe funcionar correctamente aunque el catálogo o la lista de préstamos estén vacíos.
